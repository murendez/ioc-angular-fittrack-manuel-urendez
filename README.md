
# FitTrack

## Autor/a
Manuel Urendez Molero

## Descripció
FitTrack és una aplicació web per registrar i consultar
entrenaments esportius, com córrer, anar en bicicleta
o fer exercicis de força.

L'objectiu és fer un seguiment de les activitats i
de la progressió personal.

## Versions utilitzades
- Node.js: 24.21.0
- npm: 11.19.0
- Angular CLI: 22.2.2
- Angular: 22.x
- Git: 2.54.0

## Com crear i executar el projecte
El projecte s'ha creat amb Angular CLI 22.

Per instal·lar les dependències:
```bash
npm install
```

Per executar l'aplicació:
```bash
ng serve
```

Després, obrir http://localhost:4200 al navegador.
